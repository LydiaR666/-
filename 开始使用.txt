📌 你需要做的只有3步：

┌────────────────────────────────────────────────────────────────┐
│ 第1步：安装Python依赖包                                         │
└────────────────────────────────────────────────────────────────┘

  1. 按 Win+R，输入 cmd，按回车
  2. 在黑色窗口中输入以下命令，按回车：

     pip install requests pandas openpyxl beautifulsoup4 lxml PyPDF2 python-dateutil tqdm retry

  3. 等待安装完成（看到 "Successfully installed..." 就是成功了）


┌────────────────────────────────────────────────────────────────┐
│ 第2步：转换Excel格式                                            │
└────────────────────────────────────────────────────────────────┘

  1. 双击运行：步骤1-转换Excel格式.bat
  2. 输入你的Excel文件路径：
     C:\Users\10657\Desktop\并购公告\并购公告下载.xlsx
  3. 按回车，等待转换完成
  4. 会生成新文件：并购公告下载_已转换.xlsx


┌────────────────────────────────────────────────────────────────┐
│ 第3步：运行爬虫                                                 │
└────────────────────────────────────────────────────────────────┘

  方案A：先测试（强烈推荐！）
    → 双击运行：测试运行.bat
    → 如果成功，再双击运行：一键运行.bat

  方案B：直接运行全部数据
    → 双击运行：一键运行.bat

  ⚠️  注意：运行前需要修改批处理文件中的路径！


════════════════════════════════════════════════════════════════

💡 重要提示：

1. 如果批处理文件无法运行，请修改文件中的路径：
   - 右键点击 "一键运行.bat"
   - 选择 "编辑"
   - 修改第8行和第9行的路径为你的实际路径
   - 保存后再运行

2. 运行过程中不要关闭命令窗口！

3. 查看结果：
   - 最重要的文件：爬取结果\valid_announcements.xlsx
   - 这个文件包含所有符合要求的有效公告
